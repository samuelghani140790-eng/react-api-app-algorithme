# PokéDex Dashboard

Aplikasi web sederhana untuk mencari dan menampilkan data Pokémon berdasarkan nama atau ID.

## Teknologi yang Digunakan
* React.js
* Tailwind CSS
* Vite

## Cara Menjalankan Project Secara Lokal
1. Clone repositori ini.
2. Buka terminal dan jalankan `npm install`.
3. Jalankan `npm run dev` untuk membuka di browser lokal.
